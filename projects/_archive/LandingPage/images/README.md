## 🎨 คำแนะนำการเตรียมภาพ

### Format ที่แนะนำ
- **PNG** - สำหรับภาพที่มีพื้นหลังโปร่งใส (โลโก้)
- **JPG/JPEG** - สำหรับภาพ Screenshot ทั่วไป
- **WebP** - สำหรับ Performance ที่ดีกว่า (optional)

### การ Optimize ภาพ
1. ใช้ [TinyPNG](https://tinypng.com/) หรือ [Squoosh](https://squoosh.app/) เพื่อบีบอัดภาพ
2. ตรวจสอบว่าภาพมีความละเอียดเพียงพอ (ไม่แตก)
3. สำหรับ Retina Display อาจใช้ภาพขนาด 2x

### สี Background ที่แนะนำ (ถ้าต้องสร้าง placeholder)
- Hero/Dashboard: `#f8fafc` (gray-50)
- Pages: พื้นหลังขาว หรือ gradient อ่อน
- Mobile: `#1f2937` (gray-800) สำหรับ dark theme
